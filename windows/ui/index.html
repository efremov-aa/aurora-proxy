📋Что даёт меш

  • ✓ Общие локации — доступ к узлам других участников (Германия, Нидерланды, Турция и др.)
  • ✓ Резервные маршруты — если один узел упал, трафик автоматически идёт через другой
  • ✓ Локальный обход блокировок — трафик между устройствами меша идёт напрямую
  • ✓ Общий белый список — синхронизация правил между всеми вашими прокси

🎛Политика хаба

Головной сервер управляет тем, какие вкладки видны у клиентов меша. Клиенты, подключённые по invite этого сервера, автоматически применяют политику (обновление каждые 15 сек).

🌌Топология меша–

Ваш прокси (в центре) и узлы других участников меша. Соединения активны, если трафик ходит через них.
