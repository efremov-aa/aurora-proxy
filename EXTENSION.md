# 🧩 Aurora для браузера — расширение MV3

> Мяу! Я — котик на странице: прячу рекламу, берегу твой IP и держу VPN только там,
> где реально нужно. Лапки мягкие, блокировки — быстрые. 🐾

Расширение работает на **Manifest V3** и **declarativeNetRequest**: правила применяет
браузер, а не сам котик, поэтому блокировки не тормозят страницы и не требуют
фоновых скриптов.

## 🐾 Что умеет

| Фича | Реально? | Польза |
| --- | --- | --- |
| 🛡 **Блокировка рекламы** — свои списки + YouTube (anti-adblock-надписи, телеметрия, preconnect) | ✅ DNR полностью | макс |
| 🇷🇺 **RU-байпас прямо в браузере** — русские сайты напрямую, остальное через Aurora | ✅ сервер уже отдаёт свой список доменов | макс |
| 🎯 **Режим «только этот сайт» / глобально / выкл.** | ✅ session-правила DNR | макс (главный запрос пользователей) |
| 📊 **Статус подписки в popup** — дней осталось, трафик, тариф, устройства | ✅ один запрос к мастеру | высокая |
| 💬 **Кнопка «Оплатить» прямо из popup** → Telegram-бот (покупка/триал) | ✅ монетизация, бот уже есть | макс для бизнеса |
| 🕵️ **Защита от утечек IP** — блок WebRTC/STUN (`stun.l.google.com` и т.п.) | ⚠️ частично: SDP-munging в чистом MV3 нет, блок хостов — да | высокая |
| 🧼 **Антитрекинг + очистка cookies трекеров по кнопке** | ✅ | высокая |
| 🔄 **Автообновление правил с мастера** (версия правил + диффы) | ✅ | средняя, но «живой» продукт |

### 🛡 Реклама

Свои списки фильтрации плюс отдельный набор для YouTube: anti-adblock-надписи,
телеметрия и preconnect, из-за которых видео не грузится. Правила живут в
declarativeNetRequest — браузер блокирует запросы до отправки, поэтому страница
остаётся быстрой даже на слабом канале.

### 🇷🇺 RU-байпас

Русские сайты идут **напрямую** (мимо VPN), всё остальное — через Aurora. Список
доменов отдаёт сервер (около 1375 доменов из публичных источников + статический
фолбэк), расширение превращает его в session-правила DNR, поэтому переключение
между «RU-напрямую» и «весь трафик в туннель» не требует перезапуска браузера.

### 🎯 Режимы

- **Только этот сайт** — VPN (или блокировки) только на текущем домене.
- **Глобально** — правила применяются ко всем вкладкам.
- **Выкл** — котик спит, трафик не трогаем.

### 📊 Статус подписки в popup

Один запрос к мастеру — и котик показывает: сколько дней осталось, израсходовано
лимита, текущий тариф и число устройств. Ничего лишнего в popup не показываем.

### 💬 Оплата из popup

Кнопка «Оплатить» открывает Telegram-бот: **тарифные планы VPN** (для тех, у кого
серый IP) и **дополнительные возможности Aurora**. Оплата и продление — в боте,
тариф подключается сразу.

### 🕵️ Защита от утечек IP

Блокируем STUN-серверы (`stun.l.google.com` и подобные), чтобы WebRTC не выдал
реальный адрес мимо прокси. Полное SDP-munging в чистом MV3 недоступно, поэтому
делаем блок хостов + запрет утечки через известные трекеры.

### 🔄 Обновление правил

Расширение спрашивает у сервера `rules_version` и обновляет списки, если версия
изменилась. Правила приезжают диффами, поэтому обновление экономное и «живое».

## 🔌 Серверная часть (уже в этой сборке)

`GET /api/ext/config?token=<device-ссылка>` — публичный маршрут (как `/sub`),
без origin-проверки, CORS не выставляется: расширение объявляет `host_permissions`.

```json
{
  "ok": true,
  "proxy": { "host": "10.1.0.238", "port": 8899, "type": "http" },
  "mode": "vpn",
  "ru_bypass": true,
  "blocked": false,
  "plan": "basic",
  "expires": 4102444800,
  "used": 1234,
  "limit": 107374182400,
  "buy_url": "https://t.me/aurorahomevpn_bot",
  "rules_version": "1"
}
```

Коды ответа:

| Код | Когда | Тело |
| --- | --- | --- |
| 200 | подписка активна | конфиг выше |
| 400 | нет токена / токен длиннее 256 / не ASCII | `error` + `buy_url` |
| 404 | неизвестный токен | `error` + `buy_url` |
| 403 / 410 / 429 | подписка недоступна (`disabled` / `expired` / `traffic_exhausted`) | `reason`, `status`, `buy: true`, текст с предложением купить, `buy_url` |

При отказе прокси-адрес **не отдаётся** — иначе истёкшая подписка получила бы
рабочий туннель.

Переменные окружения:

| Переменная | По умолчанию | Что делает |
| --- | --- | --- |
| `AURORA_BUY_BOT` | `@aurorahomevpn_bot` | бот для оплаты из popup |
| `AURORA_EXT_HOST` | `AURORA_HOST` → `127.0.0.1` | адрес прокси, который отдаётся расширению |
| `AURORA_RU_BYPASS` | `1` | признак активного RU-байпаса |
| `AURORA_RULES_VERSION` | `1` | версия правил расширения (для автообновления) |

Проверка контракта — `python tests/test_a075_ext_config.py` → `A075_EXT_CONFIG_OK`.

## 🐱 Домашний кот

Правила фильтрации живут в репозитории, обновления подтягиваются с мастера,
подписка и трафик считаются на сервере Aurora — расширение только рисует котиков
и жмёт кнопки. Всё остальное умеет сам Aurora. 🐾
